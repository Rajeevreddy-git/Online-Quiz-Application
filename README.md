# Online-Quiz-Application

An interactive, lightweight quiz app designed to help students and educators practice multiple-choice questions with instant feedback and scoring. Built using core front-end technologies for a smooth and responsive experience.

Features
-  Multiple-choice questions
-  Countdown timer per question
-  Instant scoring and feedback
-  Restart option after completion
-  Clean, responsive UI

 Tech Stack
- HTML – Structure and layout
- CSS – Styling and responsiveness
- JavaScript – Quiz logic, timer, scoring
Optional: Can be extended with Open Trivia DB API for dynamic questions

Future Improvements
- Integrate live questions using Open Trivia DB API
- Add progress bar and question tracker
- Store scores using localStorage
- Make it mobile-friendly with media queries
